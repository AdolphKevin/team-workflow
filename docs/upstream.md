# MATT 来源与更新

基线为 [mattpocock/skills](https://github.com/mattpocock/skills) 1.3.1，提交 `b0618bc436ad893b3c5e84e55fba86586d34a404`。许可完整保留在 `licenses/MATT-MIT.txt`。

`upstream/matt.lock.json` 逐文件记录原路径、原文哈希、发行路径和本地哈希；`upstream/matt.patch` 是完整最小差异。`scripts/check_release.py` 在隔离目录反向应用差异，验证恢复出的每份上游文件哈希；无需联网、个人插件缓存或上游安装。

复用规格、任务拆分、实现、依赖任务实施、诊断、测试先行、模块设计、领域建模、双维度审查、复盘、问题澄清、PR 描述、原型、面向代理写作和研究。配套模板、测试例子、设计说明与脚本均随所属技能保留。

适配涉及：技能命名与内部引用、统一 CS 接入、已有授权的延续、可选多代理、完整工作区审查和风险所需验证。知识规则由 CS 单独维护，团队交付工具按需启用。环境复盘仅保留环境分析方法，删除重复审查和知识维护规则。源文档不复制进 CS；不新增自动提交或外部发布行为。

更新上游时先在临时目录取得明确版本，比较变更，重新应用本地适配，再更新锁定文件和差异。验证所有内部链接、上游哈希、测试与独立技能试用后发布新版本。保留被替代版本的标签，不通过升级业务项目脚本分发。
