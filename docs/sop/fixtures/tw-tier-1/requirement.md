# 需求：店铺在线客服

确认人：业务负责人 王敏（2026-10-20）

## 背景

商家希望访客在店铺前台直接和客服对话；客服不在线时由 AI 先回复；会话长时间没人回复时提醒客服；商家可以订阅消息事件。

## 涉及仓库（各服务在本机分别用 go run 或 uv run 启动）

| 仓库 | 语言 | 职责 |
| --- | --- | --- |
| livechat-gateway | Go | 访客与客服的 WebSocket 连接、鉴权、消息转发 |
| livechat-main | Go | 会话与消息的存储、分配客服、工作台接口、延时任务、Webhook 投递 |
| livechat-common | Go | 消息结构、事件定义、签名工具（公共库，被其他 Go 仓库引用） |
| ai-reply-gateway | Go | 接收主服务的 AI 回复请求，转发给 Python 服务并回写结果 |
| ai-reply-engine | Python | 根据店铺知识库生成回复 |

## 业务要求

1. 访客在店铺前台打开聊天窗口发送消息，消息经网关到达主服务，分配到在线客服，客服在工作台实时收到。
2. 客服在工作台回复，访客在聊天窗口实时收到。
3. 店铺没有在线客服时，主服务请求 AI 回复，AI 生成的回复发给访客，并在工作台会话中标注为 AI 回复。
4. 访客消息 10 分钟内没有客服或 AI 回复时，主服务通过延时任务给店铺的客服组发提醒。
5. 商家在后台配置 Webhook 地址后，每条新消息推送一次 message.created 事件，失败重试 3 次。
6. 客服只能看到自己店铺的会话；访客只能看到自己的会话。
