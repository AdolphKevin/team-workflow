# 设计边界

本仓只发行 `team-knowledge`。它保存和读取项目的现行知识，与成员选择的开发方法无关。职责收缩依据见[已批准方案](proposals/2026-10-22-knowledge-only.md)。

## 知识与原文

规则、决策、教训、概览和词汇放在 `.tw/` 中，与代码一起评审。条目存在表示当前适用；决定改变时改写现行结论，把旧做法、放弃原因、来源与关键词放入“放弃过的做法”。项目已登记原文时，原文拥有正文，知识条目引用它。

`brief` 按路径、符号、标签、词组与关联选择知识，并给出选择原因和实际可见的索引；`read` 读取条目或登记原文。`check` 核对结构、路径与引用，`audit` 汇总健康状况。四者只读，不判断业务结论是否正确。`new` 生成待填写的条目骨架，`init` 预览或初始化，`cache` 显式重建或清除查询缓存，`version` 核对版本与技能文件完整性。

`brief` 在任务标题下说明直接与间接命中的条数，在正文来源行前写明选中依据。指定条目、符号、路径、守护测试文件及 `--tag` 属于直接命中；任务词组、放弃过的做法与关联属于间接命中。排序依次比较层级、路径具体度、独立信号数与条目标签，关联理由用于带出条目。覆盖说明与仓库状态先预留篇幅，总输出受 `--budget` 约束；JSON 的 `coverage`、`outside` 分别保存覆盖计数和其他仓库状态。

`check` 对含提交基线的条目比较其最近修改与 `verified`：核实之后只改条目其余内容而沿用基线时给警告，列出修改提交、日期、原基线及核对后可填写的当前 HEAD 与今天日期；工作区和 `--cached` 的暂存区同样核对。只有日期的基线及没有基线的决策照常做结构检查。提交历史和条目原文批量读取。

## 配置与跨仓

配置解析 `format`、`data_version`、`project`、`context`、`shared`、`documents`。格式标识使用初始化生成的固定值，数据版本为 1。旧团队字段的处理见[从 0.x 升级](install.md#从-0x-升级)。

共享仓只登记远端身份。本机路径按命令行、检出目录 `.tw/local/repositories.json`、用户级 `${XDG_CONFIG_HOME:-~/.config}/tw/repositories.json` 的顺序按键覆盖，工具只读这些映射。读取时核对仓库身份，并展示来源、实际提交与未提交状态；缺少映射时提示成员补齐。

`brief --path` 中的绝对路径和含 `..` 的路径相对当前工作目录解析，其他相对路径以仓库根为准。本仓路径规范化后参与选择；仓库外路径列在“其他仓库”，报告所在仓库、知识状态与可复制的命令，条目只读取本仓和已声明的共享仓。没有 `.tw/config.json` 时，`brief` 以 0 退出并给开工指引：有旧知识目录时列出位置及受版本管理的文件数，代理按任务与路径阅读相关旧卡并视为未核实线索，迁移按迁移指南；其余情况提示 `tw init`。`read`、`audit` 要求已初始化。

`guards` 直接引用 `仓库:文件#测试名`，核对文件与名称存在。引用只表示可追溯，运行由 CI 证明。场景编号也可作为文件中的名称，实际验收结果保存在项目验证记录。

## 本机材料

`.tw/local/` 按检出目录隔离并被 Git 忽略。运行时只管理查询缓存；路径映射由成员维护，其他材料由成员自行保留或清理。健康报告自行统计文件、大小与其他材料，不导入额外运行时。只读知识命令和退出的旧命令均不整理或删除本机材料。

`audit` 按顶层项汇总大小、文件数、最后修改日期及距今天数，按大小降序显示 `--top` 项并汇总其余项。最后修改超过 30 天的项标记供成员清理，查询缓存和路径映射标为工具管理；超过 20 MiB 的文件另列总数及前 `--top` 项。JSON 保存全部顶层项。最后修改取材料及其子目录、文件的最新时间；符号链接按链接本身统计。

`check` 核对知识及登记原文中的本机材料引用，防止只有一个人能读到的原件成为共享知识的依据。结论与关键数据写进入库文档，原始输出留在执行者本机。

## 发行与验收

唯一运行时位于 `skills/team-knowledge/scripts/tw_runtime/`，只用 Python 标准库；业务测试、运行命令和必跑要求由产品仓库脚本与 CI 承担。开发方法由使用者选择，SOP 验收与回归沉淀由 sop-board 发行。本仓自身的独立代理验收直接使用[场景文件](sop/tw-knowledge-only.yaml)，结果记入[验证记录](validation.md)，不接入外部看板。

发行检查核对单技能目录、元数据与运行时版本、文件清单、Python 编译与导入、未定义名称、说明链接及指令篇幅。包中包含知识技能与公开说明，不含本仓 `.tw/`。固定发行标签经用户发布；运行检查、代理试用和真实成员试点分别报告。
