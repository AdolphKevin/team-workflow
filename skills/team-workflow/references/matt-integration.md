# MATT 与 CS 接入约定

使用本包前，CS 已安装且项目已完成 CS 知识初始化。发现当前安装的独立 CS 技能，
读取其 SKILL.md 及其中的“开发方法与知识归属”约定，按 CS 进行只读预检。
缺少安装、初始化或可用格式时，报告缺少的前提并停止方法调用；本包不代为安装、
初始化或重建 CS。

MATT 提供开发方法，项目知识的读取、原文归属、任务记录和经验更新统一遵循 CS。
方法切换与按需分析的知识处置也由 CS 的组合约定定义，这里不维护第二份规则。

方法直接复用锁定的 MATT 源码和配套资源。沿用当前任务范围、用户选择与已有授权；
测试先行、多代理和工作树按需要采用。发布、提交、开 PR、关闭任务和生产操作沿用
已有授权。验证应满足项目实际风险及要求。

普通 MATT 调用不要求 `.team-workflow.json` 或额外交付材料。项目约定或用户需要
团队工具时，再读取[团队协作与交付](team-delivery.md)，沿用完整核验要求。
